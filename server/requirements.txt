# Runtime dependencies to import and run the engine + the full test suite.
#
# Keep this list small and honest: it is what a fresh checkout must install to
# run the server, the tests, and the content validators.
#
# pygame is required by the normal client and the full test suite. Headless
# server imports deliberately do not require it (covered by
# test_headless_import_without_pygame.py), so a deployment that never loads
# client presentation may omit it after selecting its own narrow dependency
# contract.
#
# NOTE ON PYTHON VERSION: pygame ships no cp314 wheel yet. On 3.14 use
# `pygame-ce` (which provides the `pygame` module and does ship cp314 wheels),
# or run on 3.11/3.12 as .github/workflows/server-tests.yml does.
pygame>=2.6

# toolkit/data_integrity_validator.py imports yaml unconditionally at module
# scope to validate theme-pack YAML alongside JSON/SVG.
PyYAML>=6.0

# Optional at runtime (engine/server/transport/base.py guards the import),
# but installed here so the msgpack transport contract test actually
# exercises the codec instead of being silently skipped.
msgpack>=1.0

# NOT listed on purpose: torch / transformers.
#
# They used to be here, with a comment claiming `engine/ai/llm_interface.py`
# imports them at module scope and therefore made a ~1GB ML stack a hard
# requirement just to import engine.world.world. That is no longer true: the
# only torch imports in the engine sit inside `LLMInterface._load_model`,
# *after* an unconditional early `return`, and there is no module-scope torch
# import anywhere under server/. The suite and the server run without them.
#
# If you want local-LLM ambient NPC dialogue, install them yourself
# (`pip install torch transformers accelerate`) and delete the early return in
# `_load_model`.
