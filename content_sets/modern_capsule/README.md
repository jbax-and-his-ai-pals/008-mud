# Modern Capsule

Modern Capsule is the first genre-neutral content-set proof: a small present-day exploration and conversation slice.

It intentionally enables only `inventory` and `dialogue`. There are no spells, mana, crafting recipes, quests, campaigns, or combat content. Launch it with:

```powershell
.\.conda\python.exe server\launch_content_set.py --content-set content_sets\modern_capsule --dry-run
```

Then use the normal launch command without `--dry-run` to start the server.
