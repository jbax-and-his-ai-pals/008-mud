# Phase 3: Multi-Theme Sample Games

## Goal

Prove the engine is theme-agnostic by shipping multiple high-quality sample experiences.

## Checklist

- [ ] Ship sample: classic fantasy baseline.
- [ ] Ship sample: sci-fi frontier.
- [ ] Ship sample: cyberpunk district.
- [ ] Ship sample: post-apocalyptic settlement.
- [ ] Ensure each sample uses same runtime APIs and packaging flow.
- [ ] Add sample-specific docs that show how to mod/extend each one.
- [ ] Ship at least one finite adventure sample with explicit ending states.
- [ ] Ship at least one co-op party sample with shared progression/reward policy.

## Exit Gate

- [ ] At least 3 distinct themes run on one runtime without bespoke engine forks, including finite-adventure and co-op party exemplars.
