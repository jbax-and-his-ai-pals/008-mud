# Documentation Track

## Goal

Provide comprehensive docs so users can learn, build, operate, and customize servers confidently.

## Audience Buckets

- Players
- Server operators/admins
- GMs/moderators
- World creators/content authors
- Mod/plugin developers

## Required Doc Sets

- [ ] Client manual:
  - connect/reconnect,
  - accessibility settings,
  - desktop/mobile UX differences,
  - troubleshooting.
- [ ] Server operator guide:
  - installation,
  - master config,
  - profiles and feature toggles,
  - security/authz and entitlement detail levels,
  - backups/restore.
- [ ] GM handbook:
  - GM auth lifecycle,
  - operator actions,
  - moderation and safety controls.
- [ ] Data/reference docs:
  - protocol envelope and event reference,
  - server config schema,
  - content schema reference (entities/components/assets),
  - pack/mod compatibility policy.
- [ ] Creator tutorials:
  - "first server in 30 minutes",
  - "build a world with editor path",
  - "enable/disable gameplay systems",
  - "publish a sample pack".
- [ ] API/reference generation pipeline (single source of truth where possible).

## Exit Gate

- [ ] New users can self-serve setup and customization; core support load shifts from "how do I start?" to advanced usage.
